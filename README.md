# UC‑15: Safe Cargo Assignment (try‑catch‑finally)
## What it does
Assigns cargo to goods bogies while safely handling unsafe cargo combinations using a custom runtime exception and try‑catch‑finally.
## Main Steps
- Define a custom runtime exception
- Validate cargo assignment rule
- Throw exception for unsafe cargo
- Catch and handle the exception
- Run finally block for logging

## Key Concepts

- Custom runtime exception (CargoSafetyException)
- Exception handling (try‑catch‑finally)
- Safe assignment logic
- Runtime validation pattern

## Goal
Ensure cargo assignment is safe and validated at runtime, with clean exception handling and reliable logging.
