# UC‑2: Add Passenger Bogies
## Overview
This use case adds passenger bogies to the train and manages them using an ArrayList.
## What It Does
- Adds new bogies (e.g., Sleeper, AC Chair, First Class)
- Removes a bogie from the list
- Checks if a bogie exists
- Shows the final list of passenger bogies
## Purpose
To learn basic CRUD operations (Add, Remove, Search, Display) using ArrayList in the Train App.
