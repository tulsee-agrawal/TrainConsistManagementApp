# UC‑19: Binary Search for Bogie ID

## What it does
Searches for a specific bogie ID in a sorted array using the Binary Search algorithm.

## Main Steps
- Create array of bogie IDs  
- Sort the array (precondition)  
- Define key to search  
- Apply Binary Search(left, right, mid)  
- Print whether the bogie was found  
- Show completion message
- 
## Key Concepts
- Binary Search (divide‑and‑conquer)  
- Requires sorted data  
- Midpoint comparison and range narrowing  
- compareTo() for String ordering



## Goal
Demonstrate an optimized search approach on sorted data with simple, readable code.
