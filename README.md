# UC‑17: Sort Bogie Names Using Arrays.sort()
## What it does
Sorts bogie type names alphabetically using Java’s built‑in Arrays.sort().
## Main Steps
- Create an array of bogie names
- Print the original order
- Call Arrays.sort(names)
- Print the sorted order
- Show completion message
## Key Concepts

- Built‑in array sorting: Arrays.sort()
- Lexicographical (alphabetical) order for String
- Simple console I/O

## Goal
Demonstrate fast, library‑based sorting for bogie names with minimal code.
