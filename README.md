# UC‑16: Manual Sorting using Bubble Sort
## What it does
Manually sorts passenger bogie capacities in ascending order using the Bubble Sort algorithm (no built‑in sort utilities).
## Main Steps
- Create an array of bogie capacities
- Print the original order
- Run Bubble Sort (compare adjacent values, swap if needed)
- Repeat passes until fully sorted
- Print the sorted order
- Show completion message

## Key Concepts
- Bubble Sort (adjacent comparisons + swaps)
- In‑place sorting (no extra array)
- Nested loops
- Time complexity: O(n²)

## Goal
Demonstrate algorithmic sorting logic using Bubble Sort without relying on utility methods.
