# UC‑18: Linear Search for Bogie ID
## What it does
Searches for a specific bogie ID inside an array using Linear Search (sequential traversal).
## Main Steps
- Create an array of bogie IDs
= Choose a searchId
- Traverse the array element‑by‑element
- Stop when a match is found
- Print search result
- Show completion message
## Key Concepts
- Linear Search algorithm
- Sequential traversal
- Break on match
- Boolean flag for result

## Goal
Demonstrate simple Linear Search logic without using built‑in search utilities.
