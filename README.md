# UC‑11: Validate Train ID and Cargo Code
## What it does
Validates Train ID and Cargo Code using Regular Expressions.
## Main Steps

- Read Train ID
- Read Cargo Code
- Apply regex patterns
- Print whether each value is valid

## Inputs

- Train ID (Format: TRN‑1234)
- Cargo Code (Format: PET‑AB)

## Outputs

- “Train ID Valid: true/false”
- “Cargo Code Valid: true/false”

## Key Ideas

- Pattern matching
- Regex validation
- Simple pass/fail output

## Goal
Ensure both Train ID and Cargo Code follow the correct format.
